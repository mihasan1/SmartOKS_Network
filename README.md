# 🖧 NetPlanner

Аналог Cisco Packet Tracer на Node.js: **планировщик помещений** + **конструктор локальных сетей** с видимыми проводами и симуляцией.

![stack](https://img.shields.io/badge/stack-Node.js%20%2B%20Canvas-3ea6ff)

## Возможности

- **Планировка помещений** — рисование комнат и стен/перегородок по сетке.
- **Сетевые устройства:** 🖥️ ПК · 💻 Ноутбук · 🗄️ Сервер · 🖨️ Принтер · 🔀 Коммутатор · ⚹ Концентратор · 📶 Wi-Fi роутер · 📡 Точка доступа.
- **Видимые провода** — витая пара и оптоволокно, с провисом и коннекторами на концах.
- **Wi-Fi** — радиус покрытия у роутеров/точек доступа, беспроводное подключение устройств в зоне.
- **Авто-IP** — раздача адресов `192.168.X.0/24` по сегментам сети, шлюз на роутере.
- **Симуляция** — подсветка живых/мёртвых линков, анимация **PING** по маршруту с выводом в консоль.
- **Сохранение проектов** — на сервере (`data/*.json`) и автосейв в localStorage.

## Технологии

- **Бэкенд:** Node.js + Express — раздача статики и хранение проектов.
- **Фронтенд:** HTML5 Canvas + чистый JS — рендеринг, drag&drop, зум/панорама, сетевая логика.

## Запуск

```bash
npm install
npm start
```

Открыть http://localhost:3000

## Управление

| Действие | Как |
|---|---|
| Добавить устройство | Перетащить из палитры на холст |
| Комната / Стена | Инструменты `▭` / `／`, рисовать мышью |
| Провод | Инструмент `🔌`, кликнуть на два устройства |
| Вкл/выкл питание | Двойной клик по устройству |
| Масштаб | Колесо мыши |
| Панорама | Средняя кнопка или Пробел+тащить |
| PING | Панель «Свойства» устройства → выбрать цель → ▶ |

Горячие клавиши: `V` выбор · `R` комната · `W` стена · `C` провод · `E` удаление · `Del` удалить выбранное.
